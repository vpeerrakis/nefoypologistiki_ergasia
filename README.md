# Εργασία Νεφοϋπολογιστικής - K8s HPA

Αυτό το repository περιέχει τα αρχεία για την εργασία του μαθήματος της Νεφοϋπολογιστικής. Σκοπός της άσκησης ήταν να δούμε στην πράξη πώς λειτουργεί η αυτόματη οριζόντια κλιμάκωση (Horizontal Pod Autoscaler - HPA) στο Kubernetes για μια εφαρμογή ανάλογα με το φόρτο που δέχεται.

Φτιάξαμε 3 αρχεία YAML :

* **deployment.yaml**: Σηκώνει την εφαρμογή `php-apache`. Το πιο σημαντικό εδώ ήταν να βάλουμε `requests` στη CPU (200m), γιατί αλλιώς το HPA δεν θα είχε μέτρο σύγκρισης για να δουλέψει.
* **service.yaml**: Φτιάχνει ένα Service στο port 80 για να μπορεί να δέχεται κίνηση η εφαρμογή.
* **hpa.yaml**: Εδώ ρυθμίσαμε τον autoscaler. Του είπαμε να ξεκινάει με 1 pod και αν η μέση χρήση της CPU περάσει το 50%, να ανεβάζει τον αριθμό των pods μέχρι το πολύ 5.

## Πώς να το τρέξετε

Για να ανεβάσουμε τα αρχεία στον cluster του εργαστηρίου, τρέχουμε:
```bash
kubectl apply -f deployment.yaml -f service.yaml -f hpa.y
